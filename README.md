# Юридический AR-сканер

Офлайн Android-приложение: наводите камеру телефона на бумажный юридический документ — приложение распознаёт русский текст, находит в нём ссылки на статьи законов и рисует поверх изображения всплывающие карточки с названием статьи, кратким содержанием, сроками и рисками. Тап по карточке открывает диалог с полным текстом статьи.

Интернет для работы приложения **не нужен**: распознавание выполняет локальный движок Tesseract, тексты статей хранятся в локальной базе Room, которая заполняется при первом запуске.

## Возможности

- Полноэкранное живое превью камеры (CameraX, задняя камера, книжная ориентация).
- Распознавание русского текста прямо на устройстве (Tesseract4Android, язык `rus`).
- Поиск ссылок на нормы права регулярными выражениями, например:
  - «ст. 309 ГК РФ»;
  - «ч. 1 ст. 12.8 КоАП РФ»;
  - «ст. 158 УК РФ»;
  - «п. 2 ст. 310»;
  - «ГК РФ, ст. 395».
- Оверлей поверх документа:
  - прямоугольники вокруг распознанных текстовых блоков;
  - линии-выноски от найденной ссылки к карточке;
  - карточки с названием статьи, кратким содержанием, сроком и уровнем риска (цвет риска: зелёный, оранжевый, красный).
- Тап по карточке — диалог с полным текстом статьи, сроками, рисками и распознанным фрагментом.
- Плавающая кнопка (FAB) в правом нижнем углу включает и выключает оверлей.
- Строка состояния сверху: сколько ссылок найдено, сколько блоков распознано, сколько статей в базе.
- Нижняя плашка «Найдено» — список всех найденных за сеанс ссылок; тап по ней открывает список, тап по строке списка — карточку статьи.
- Всё приложение и все его тексты — на русском языке.

## Требования к компьютеру

- Android Studio Hedgehog (2023.1.1) или новее.
- JDK 17 (входит в состав Android Studio, отдельная установка не нужна).
- Android SDK: платформа 34 (`compileSdk 34`, `targetSdk 34`) и Build-Tools 34.
- Свободное место: около 3 ГБ на SDK и кэш Gradle.
- Доступ в интернет **только для первой сборки** — Gradle скачает библиотеки. Сама программа работает полностью офлайн.
- Телефон или эмулятор с Android 7.0 (API 24) и выше и с камерой.

Внутри появится папка с проектом (её имя повторяет имя архива) — именно её и нужно открывать в Android Studio: в ней лежат `settings.gradle` и `gradlew`. В этой инструкции дальше она называется «папка проекта».

## Шаг 3. Проверьте файл модели русского языка

В этой копии репозитория модель уже лежит по нужному пути, ничего скачивать не нужно:

```
папка проекта/app/src/main/assets/tessdata/rus.traineddata   (около 3,7 МБ)
```

Если файла нет (например, вы собираете проект из репозитория, где папка `app/src/main/assets/tessdata` сохранена пустой через служебный файл `.gitkeep`), то выполните следующее.

Скачайте файл rus.traineddata по ссылке https://github.com/tesseract-ocr/tessdata_fast/raw/main/rus.traineddata и положите его в папку app/src/main/assets/tessdata/rus.traineddata. Без этого файла распознавание русского языка работать не будет.

Имя файла пишется строчными буквами, расширение `.traineddata`. Файл из набора `tessdata_fast` — «быстрая» модель, она даёт лучшее соотношение скорости и качества для съёмки с телефона. При желании её можно заменить на более точную модель `rus.traineddata` из наборов `tessdata_best` (около 15 МБ) или `tessdata` (около 44 МБ): просто положите файл с тем же именем в ту же папку, код менять не нужно.

Если файла не будет, приложение запустится, но в строке состояния появится сообщение «Не найден файл rus.traineddata в папке app/src/main/assets/tessdata…», и карточки появляться не будут.

## Шаг 4. Откройте проект в Android Studio

1. Запустите Android Studio.
2. Выберите `File` → `Open…` и укажите папку `LegalArScanner-main`.
3. Дождитесь окончания синхронизации Gradle (индикатор выполнения в нижней части окна; первая синхронизация занимает 5–15 минут, потому что скачиваются библиотеки и Gradle 8.4).
4. Если Android Studio предложит обновить Gradle или плагин сборки — откажитесь: проект рассчитан на Gradle 8.4 и Android Gradle Plugin 8.1.4.
5. Если появится сообщение `SDK location not found`, нажмите в нём ссылку для установки недостающих компонентов либо создайте в корне проекта файл `local.properties` со строкой (путь к вашему SDK):
   - Windows: `sdk.dir=C\:\\Users\\ИМЯ\\AppData\\Local\\Android\\Sdk`
   - macOS / Linux: `sdk.dir=/home/ИМЯ/Android/Sdk`

Файл `local.properties` в репозиторий не попадает — он описан в `.gitignore`.

## Шаг 5. Соберите APK

**Отладочный APK (быстрый способ, подпись создаётся автоматически):**

1. `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`.
2. Дождитесь уведомления `APK(s) generated successfully` и нажмите в нём `locate`.
3. Файл будет лежать здесь:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```

**Сборка из командной строки** (в папке проекта):

- Windows:
  ```
  gradlew.bat assembleDebug
  ```
- macOS / Linux:
  ```
  chmod +x gradlew
  ./gradlew assembleDebug
  ```

**Release-APK** собирается командой `assembleRelease` (в Android Studio: `Build` → `Generate Signed Bundle / APK…` → `APK` → создать или выбрать keystore). В release-сборке включены минификация и сжатие ресурсов, правила для R8 лежат в `app/proguard-rules.pro`. Без подписи телефон release-APK не установит, поэтому для проверки удобнее отладочная сборка.

## Шаг 6. Установите приложение на телефон

Способ 1 — кабелем через Android Studio:

1. На телефоне включите «Режим разработчика» (в настройках «О телефоне» семь раз нажмите «Номер сборки») и «Отладку по USB».
2. Подключите телефон кабелем, разрешите отладку на экране телефона.
3. Выберите устройство в списке сверху и нажмите зелёный треугольник `Run`.

Способ 2 — командой adb:

```
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Способ 3 — без компьютера:

1. Скопируйте `app-debug.apk` на телефон (мессенджер, облако, карта памяти).
2. Откройте файл на телефоне и разрешите «Установку из неизвестных источников» для вашего файлового менеджера или браузера.
3. Установите и запустите «Юридический AR-сканер».
4. При первом запуске разрешите доступ к камере — без него сканер не работает.

## Шаг 7. Как пользоваться

1. Запустите приложение и разрешите доступ к камере.
2. Наведите камеру на документ так, чтобы страница занимала почти весь кадр, держите телефон параллельно бумаге на расстоянии 25–35 см.
3. Дождитесь резкости: распознавание идёт примерно раз в 0,7 секунды, на каждый кадр движку нужно 1–3 секунды в зависимости от устройства.
4. Когда ссылка найдена, рядом с текстовым блоком появляется карточка, а сам блок подсвечивается жёлтой рамкой.
5. Нажмите на карточку — откроется диалог с полным текстом статьи, сроками и рисками.
6. Кнопка в правом нижнем углу скрывает и показывает оверлей (удобно, чтобы просто читать документ).
7. Плашка «Найдено» внизу слева хранит до восьми последних найденных ссылок — по тапу открывается список.

Советы для лучшего распознавания: хорошее равномерное освещение без бликов, тёмный текст на светлой бумаге, неподвижные руки или упор, съёмка одной страницы целиком (распознавание настроено на размер кадра 1280×960).

### Откуда берётся Tesseract4Android

Библиотека `cz.adaptech.tesseract4android:tesseract4android:4.7.0` публикуется **только** в репозитории JitPack, поэтому в `settings.gradle` добавлен репозиторий `https://jitpack.io` с ограничением по группе (чтобы остальные зависимости по-прежнему брались только из Google и Maven Central):

```
maven {
    url 'https://jitpack.io'
    content {
        includeGroup 'cz.adaptech.tesseract4android'
    }
}
```

Удалять этот блок нельзя — без него сборка завершится ошибкой «Could not find cz.adaptech.tesseract4android:tesseract4android:4.7.0».

## Как работает распознавание

1. CameraX отдаёт кадры в `ImageAnalysis` со стратегией «оставлять только последний»: если предыдущий кадр ещё обрабатывается, новый отбрасывается — очередь не растёт.
2. Дополнительно кадры прореживаются по времени (не чаще одного распознавания в 700 мс).
3. Кадр преобразуется в `Bitmap` методом `ImageProxy.toBitmap()` и **поворачивается** на угол `imageInfo.rotationDegrees` (этот метод поворот не применяет, а без него текст лежит на боку и не читается).
4. Одним проходом рисования изображение переводится в градации серого и повышается контраст (`ColorMatrix`: насыщенность 0, контраст 1,25 относительно средней яркости 128) — так Tesseract стабильнее работает при неровном освещении.
5. При первом кадре модель `rus.traineddata` копируется из `assets` в `filesDir/tessdata`, после чего движок инициализируется: `init(filesDir.absolutePath, "rus")`, режим разбиения страницы `PSM_AUTO`, сохранение пробелов между словами. Инициализация выполняется в фоновом потоке анализа, а не в главном, поэтому интерфейс не подвисает; при неудаче делается до трёх попыток, а причина выводится в строку состояния на русском языке.
6. Распознавание: `setImage(bitmap)` → `getUTF8Text()` → обход `getResultIterator()` по уровням `RIL_BLOCK` и `RIL_TEXTLINE` с получением текста и координат `getBoundingRect(level)`. Итератор освобождается (`delete()`), результат распознавания сбрасывается (`clear()`).
7. По тексту каждой строки и каждого блока регулярными выражениями ищутся ссылки двух видов: «ст. 309 (ГК РФ)?» и «ГК РФ … ст. 309», с необязательной частью или пунктом («ч. 1», «п. 2», «подп. 3», «абз. 2»).
8. Для каждой найденной ссылки в базе Room ищется статья: сначала точное совпадение «кодекс + статья + часть», затем «кодекс + статья», затем только номер статьи. Результат кэшируется, повторные запросы к базе не выполняются.
9. Координаты блоков и карточек пересчитываются из системы координат распознанного кадра в координаты экрана (превью отображается в режиме `fitCenter`, поэтому пересчёт учитывает масштаб и смещение) и передаются в `OverlayView`.
10. `OverlayView` рисует рамки блоков, выноски и карточки; карточки раскладываются так, чтобы по возможности не перекрывать друг друга. Тап по карточке передаёт статью в `MainActivity`, которая показывает диалог.
11. Движок Tesseract — это нативная библиотека, поэтому он освобождается методом `recycle()` под той же блокировкой, под которой идёт распознавание: это исключает обращение к уже освобождённой памяти.

## Статьи в локальной базе

База создаётся при первом запуске и заполняется пятью статьями (повторно строки не вставляются, данные не дублируются):

| Кодекс | Статья | Тема | Уровень риска |
| --- | --- | --- | --- |
| ГК РФ | 309 | Исполнение обязательств | средний |
| ГК РФ | 310 | Недопустимость одностороннего отказа от исполнения обязательства | высокий |
| ГК РФ | 395 | Ответственность за неисполнение денежного обязательства | средний |
| УК РФ | 158 | Кража (части 1–4, примечания) | высокий |
| КоАП РФ | 12.8 | Управление транспортным средством в состоянии опьянения (части 1–3) | высокий |

Для каждой статьи хранятся: название, краткое содержание, полный текст, сроки (давность, порядок уплаты, процессуальные сроки), описание рисков и уровень риска. Все тексты — на русском языке.

Чтобы добавить свою статью, допишите ещё один объект `LegalReference(...)` в список `SeedCatalog.references()` в файле `app/src/main/java/com/shapovalov/legalar/AppDatabase.kt`. После этого удалите приложение с устройства (или увеличьте `VERSION` базы) — заполнение выполняется только при пустой таблице.

## Частые проблемы

| Что видно | Причина и решение |
| --- | --- |
| `Could not find cz.adaptech.tesseract4android:tesseract4android:4.7.0` | Нет доступа к JitPack. Проверьте, что блок `maven { url 'https://jitpack.io' … }` присутствует в `settings.gradle`, что компьютер в интернете (или прокси настроен в `gradle.properties`), и выполните `File` → `Sync Project with Gradle Files`. |
| На экране: «Не найден файл rus.traineddata…» | Не выполнен шаг 3. Скачайте модель и положите её в `app/src/main/assets/tessdata/rus.traineddata`, затем пересоберите приложение. |
| `SDK location not found` | Не указан Android SDK. Установите SDK через Android Studio или создайте `local.properties` со строкой `sdk.dir=…` (см. шаг 4). |
| Чёрный экран и надпись про недоступность камеры | Не выдано разрешение на камеру (выдайте в настройках приложения) либо у устройства/эмулятора нет задней камеры. На эмуляторе включите `Camera: Emulated` или `Webcam0` в настройках AVD. |
| Распознавание ничего не находит | Плохое освещение, мелкий шрифт, сильный наклон или смаз. Поднесите документ ближе, выровняйте телефон, добавьте света; распознавание рассчитано на печатный текст, рукописный не читается. |
| Первый кадр обрабатывается долго | При первом запуске копируется модель (3,7 МБ) и загружается нативная библиотека — это нормально, дальше распознавание идёт быстрее. |
| APK не устанавливается на телефон | Версия Android ниже 7.0 (нужен API 24+), либо включена проверка подписи: отладочный APK ставится только с разрешением «установка из неизвестных источников». |
| Приложение занимает много места | В APK без сжатия включён файл модели (около 3,7 МБ) — это сделано намеренно (`noCompress "traineddata"`), иначе Tesseract не сможет прочитать модель из памяти. |

## Ограничения

- Приложение учебное: тексты статей приведены в справочных целях и могут не соответствовать действующей редакции закона. Перед принятием решений сверяйтесь с официальными источниками.
- Распознавание работает только с печатным текстом, рукописный текст не поддерживается.
- Оверлей — это двумерная отрисовка поверх превью камеры; технология ARCore не используется, привязки к трёхмерному пространству нет.
- База содержит пять статей; список найденных ссылок ограничен восемью последними.
